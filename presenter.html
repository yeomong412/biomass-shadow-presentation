대본 파일을 선택해 주세요.

두 화면에 배치하는 방법
  1. HDMI를 연결하고 Windows 키 + P에서 확장을 선택합니다.
  2. 발표자 도구는 노트북에 둡니다. 청중 창을 선택해 Windows 키 + Shift + ← 또는 →로 외부 화면에 옮깁니다.
  3. 외부 화면의 청중 창에서 F 키를 눌러 슬라이드를 전체 화면으로 띄웁니다.
  4. 발표자 도구로 돌아와 대본을 열고 타이머를 시작합니다. 방향키, 스페이스바, Page Up / Down으로 장을 넘길 수 있습니다.
