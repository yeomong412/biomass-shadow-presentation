# 바이오매스 발전의 편익과 산림 훼손의 공간적 분포

45분 분량의 HTML 발표자료입니다. 발표 슬라이드 30장과 참고문헌 1장으로 구성되어 있습니다. `index.html`을 브라우저에서 열면 실행됩니다. 정적 웹사이트이므로 GitHub Pages에 그대로 배포할 수 있습니다.

## 조작

- 오른쪽 방향키, 스페이스바, PageDown: 다음 장
- 왼쪽 방향키, PageUp: 이전 장
- Home / End: 처음 / 마지막
- O: 전체 슬라이드 목록, F: 전체화면
- 화면 좌우 끝 클릭, 모바일 좌우 스와이프 지원
- 브라우저 인쇄: 장별 PDF 출력

## 발표자 도구

1. HDMI를 연결하고 Windows 키 + P에서 **확장**을 선택합니다. 복제 모드는 같은 화면을 두 곳에 표시합니다.
2. Chrome 또는 Edge에서 발표자료를 열고 오른쪽 위의 **발표자 도구**를 누릅니다. 창이 뜨지 않으면 이 사이트의 팝업을 허용합니다.
3. 발표자 창은 노트북에 둡니다. 원래 발표 창을 선택해 Windows 키 + Shift + ← 또는 →로 외부 화면에 옮긴 뒤 F를 눌러 전체 화면을 켭니다. 전체 화면은 Esc로 나옵니다.
4. 발표자 창에서 **대본 파일 열기**로 저장소의 [speaker-notes.md](speaker-notes.md)를 내려받아 선택합니다. 현재 장의 키워드 대본이 표시됩니다. 시간 구간이 있는 이전 대본도 읽을 수 있습니다. **시작**을 누르면 45분 타이머가 시작됩니다.
5. 발표자 창의 이전/다음 버튼, 방향키, 스페이스바, Page Up / Down으로 청중 창을 조작합니다. 슬라이드 선택 메뉴로 장을 건너뛸 수 있고, 지도 선택 버튼은 두 창에 함께 적용됩니다.

대본은 발표자 창이 로컬 파일에서 읽습니다. 두 창 사이에는 슬라이드와 지도 선택 상태만 전달됩니다. 발표자 창을 닫고 새로 열면 대본을 다시 선택합니다.

## 키워드 대본

[speaker-notes.md](speaker-notes.md)는 기존 발표대본을 개정한 슬라이드 1~30의 말할 순서입니다. 키워드, 명사구, 짧은 절을 하이픈 목록으로 정리했습니다. 출처와 수치의 집계 범위는 [speaker-notes-sources.md](speaker-notes-sources.md)에 기록했습니다. 참고문헌은 기존 31번 슬라이드에 유지합니다.

## 수정

- 슬라이드 구성과 내용: `js/slides.js`
- 디자인과 8px 간격 시스템: `css/presentation.css`
- 탐색과 키보드 조작: `js/presentation.js`
- 전환과 내용 등장 효과: `js/slide-motion.js`

## 전환 효과

- 일반 본문: 360ms 페이드와 32px 수평 이동. 이전 장으로 돌아갈 때는 방향이 반전됩니다.
- 장 구분 또는 밝은/어두운 배경 전환: 420ms 페이드와 가벼운 확대(98.4%에서 100%). 지도는 확대나 이동 없이 페이드만 적용합니다.
- 지도: 320ms 페이드. 장 구분 지점에서는 420ms로 전환하고 이미지의 위치와 크기를 유지합니다.
- 제목, 카드, 질문 등: 300ms 등장에 최대 160ms의 시차를 더해 전체 효과가 460ms 안에 끝납니다. 카드 안의 문장을 다시 따로 움직이지 않습니다.
- 공통 이징: `cubic-bezier(0.22, 1, 0.36, 1)`. 연속 입력은 이전 효과를 정리한 뒤 최신 이동을 바로 반영합니다.
- 운영체제의 동작 줄이기 설정을 따르면 전환과 내용 등장 효과를 생략합니다. 인쇄를 시작해도 진행 중인 효과를 정리하고 전체 내용을 출력합니다.

Chrome에서 기존 이동 키, 연속/역방향 이동, 지도 탭, 전체화면, 목록 이동, 발표자 연동, 동작 줄이기, 31페이지 인쇄를 검수했습니다. 슬라이드 데이터와 원본 지도 PNG는 수정하지 않았습니다.
